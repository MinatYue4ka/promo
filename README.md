# MINATSUKI

Сайт-портфолио: разработка сайтов, мобильных приложений и Telegram-ботов.

**Открыть:** https://minatyue4ka.github.io/promo/

## Что где лежит

| Файл | Что это |
| --- | --- |
| `index.html` | Главная страница: разметка, стили и логика (появление блоков, FAQ, прогресс-бар) |
| `promo.html` | Промо-ролик, встроенный в главную страницу через iframe |
| `images.js` | Ссылки на картинки для ролика — правится в первую очередь |
| `promo.jsx` | Сцены ролика: мессенджер, редактор кода, терминал, превью проектов |
| `animations-v2.jsx` | Движок анимации: таймлайн, сцены, спрайты, полоса воспроизведения |
| `ios-frame.jsx` | Рамка телефона для сцен с мобильным приложением |
| `tweaks-panel.jsx` | Панель настроек ролика, видна только в режиме редактирования |
| `image-slot.js` | Слот под картинку с подстановкой заглушки |
| `support.js` | Рантайм: собирает страницу и компилирует JSX прямо в браузере |
| `_ds/` | Токены оформления и классы компонентов |

## Запуск на своём компьютере

Сборка не нужна, это статические файлы. Но открывать `index.html` двойным кликом нельзя — браузер не даст подгрузить JSX с `file://`. Поднимите любой локальный сервер в папке проекта:

```bash
python -m http.server 8000
```

и откройте http://localhost:8000

## Как поменять картинки в ролике

Все ссылки собраны в `images.js`, внутри подписано, какая картинка в какой сцене показывается. Ссылка должна вести прямо на файл и заканчиваться на `.jpg`, `.png` или `.webp`.

## Как поменять текст и контакты

Тексты главной страницы, ссылки на Telegram и блок вопросов-ответов лежат прямо в `index.html`. Реплики и подписи в ролике — в `promo.jsx`, порядок и длительность сцен — в `promo.html` в переменной `OM_SCENES`.

## Обновление сайта

GitHub Pages раздаёт ветку `main` из корня репозитория. После `git push` сайт обновляется за одну-две минуты.
